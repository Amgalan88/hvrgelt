# DB migration-ууд

Supabase Dashboard → **SQL Editor** → файлын агуулгыг бүтнээр нь хуулж **Run**.
Дугаарын дарааллаар ажиллуулна. Нэг файлыг хоёр удаа ажиллуулсан ч аюулгүй
(`if not exists` хэлбэрээр бичсэн).

| Файл | Юу хийдэг | Төлөв |
|---|---|---|
| `00_schema.sql` | Анхны хүснэгтүүд | ✅ |
| `02.sql` – `10.sql` | Хаяг, хурдан захиалга, газрууд, тохиргоо, push | ✅ |
| `11-17_all.sql` | 11–17-г нэг дор (үйлчилгээ, баримт, төлбөр, үнэлгээ, санал, бараа) | ✅ |
| `11.sql` – `17.sql` | Дээрхийн тусдаа хувилбар (түүхэнд үлдээв) | ✅ |
| `18.sql` | Утасны дугаарын нууцлал — **сонголттой**, одоохондоо бүү ажиллуул | — |
| `19.sql` | Газрын зураг: захиалгын координат, хүргэгчийн байршил | ✅ |
| `20.sql` | Гараас гарт, хүргэгч хайж эхэлсэн цаг, газрын байршил | ✅ |
| `21.sql` | Захиалгын push мэдэгдэл (webhook → api/notify) | ✅ |
| `22.sql` | **DB-г хаах** (RLS — хэн юу хийж болох) | ✅ |
| `22_rollback.sql` | 22-ыг буцаах — зөвхөн асуудал гарвал | — |
| `23.sql` | Хэрэглэгчийн профайл зураг | ⏳ ажиллуулах |

Шинэ migration нэмэхдээ дараагийн дугаараар (`24.sql`) энэ хавтсанд үүсгэж,
энэ хүснэгтэд мөр нэмнэ.
